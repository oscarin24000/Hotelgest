\# Requerimientos del sistema HotelGest



\## Requerimientos funcionales



| Código | Requerimiento |



| RF1 | El sistema debe permitir iniciar sesión según el rol (huésped, recepcionista, administrador). |

| RF2 | El administrador podrá registrar, editar y eliminar habitaciones, con su tipo y tarifa. |

| RF3 | El recepcionista podrá registrar y consultar huéspedes. |

| RF4 | El huésped podrá consultar las habitaciones disponibles por fechas. |

| RF5 | El sistema debe permitir crear una reserva y evitar reservas duplicadas para la misma habitación y fechas. |

| RF6 | El huésped o el recepcionista podrá cancelar una reserva. |

| RF7 | El recepcionista podrá registrar el check-in y el check-out. |

| RF8 | El sistema debe calcular el total de la estadía y generar la factura. |

| RF9 | El administrador podrá generar reportes de ocupación e ingresos. |



\## Requerimientos no funcionales



| Código | Tipo | Requerimiento |


| RNF1 | Usabilidad | La interfaz debe ser sencilla para que el recepcionista la aprenda rápido. |

| RNF2 | Rendimiento | La consulta de disponibilidad debe responder en pocos segundos. |

| RNF3 | Seguridad | Las contraseñas deben almacenarse protegidas y el acceso depende del rol. |

| RNF4 | Disponibilidad | El sistema debe estar disponible las 24 horas, porque el hotel opera todo el día. |

| RNF5 | Mantenibilidad | El código estará organizado por capas para facilitar los cambios. |

| RNF6 | Compatibilidad | Debe funcionar en los navegadores más comunes. |

\## Problema

El hotel lleva las reservas en cuadernos o Excel, lo que causa reservas

duplicadas, habitaciones mal asignadas y falta de control de la ocupación.



\## Objetivo

Centralizar la información en un sistema que automatice reservas,

check-in, check-out y facturación.



\## Usuarios

Huésped, Recepcionista y Administrador.



\## Funcionalidades principales

\- Gestión de habitaciones

\- Gestión de huéspedes

\- Reservas

\- Check-in y check-out

\- Facturación

\- Reportes

Tres capas: interfaz de usuario, lógica de negocio y acceso a datos.
